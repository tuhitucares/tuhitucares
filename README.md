## How a visit works

1. **Book.** Tell Care Pro AI what is wrong, in Hindi or English. Red flags go to 108.
2. **Match.** The nearest certified Sarathi nurse accepts, and you follow the trip live.
3. **At the door.** Consent first, then a guided check-up and vitals with automatic alerts.
4. **Doctor.** A registered doctor reviews and signs, joins by video, or refers.
5. **Treated.** The nurse treats only on the doctor's signed orders.

**Safety built in:** the AI can only raise an alert, never lower it. Nothing reaches the patient until a doctor signs.
Only certified, ID-checked carers are sent.

## The name

The name comes from the Hindi "tu hi tu": only you. Every visit is about one person, the patient.
